[이전 글](/blog/building-this-blog)에서 블로그를 처음 만들고 배포하는 과정을 다뤘다.
이번 글에서는 그 다음 날 진행한 구조 개선 작업을 정리한다.

---

## 문제: 글이 전부 한 곳에 쌓인다

기본 템플릿의 블로그는 모든 글이 `/blog` 아래 한 곳에 나열되는 구조다.
프로젝트 시리즈, 공부 기록, 일반 글이 섞여 있으면 방문자가 전체 맥락을 파악하기 어렵다.

원하는 구조는 이랬다.

```
네비게이션: Home | Blog | Projects | Study | About

/projects  → 진행 중인 프로젝트 목록
/study     → 공부 주제별 목록 (Backend, ADP, Web Dev)
```

---

## 태그를 카테고리처럼 쓰기

Next.js 새 페이지를 많이 만들지 않아도 되는 방법을 선택했다.
이 템플릿은 태그별 글 목록 페이지(`/tags/[tag]`)를 기본으로 제공한다.

핵심 아이디어: **Projects와 Study 페이지의 각 항목이 태그 페이지로 연결되도록 한다.**

예를 들어 채용공고 프로젝트 관련 글에 `job-crawler` 태그를 달면,
`/projects`에서 그 카드를 클릭했을 때 `/tags/job-crawler`로 이동해 관련 글 전체를 볼 수 있다.

```
/projects → 채용공고 트렌드 분석 카드 → /tags/job-crawler → 관련 글 목록
/study    → Backend 카드             → /tags/backend     → 관련 글 목록
```

새로운 기능을 만들지 않고 기존 태그 시스템을 활용한 방식이다.

---

## 변경한 파일들

### 1. 네비게이션 수정

`data/headerNavLinks.ts`에서 Tags를 제거하고 Study를 추가했다.
Tags 페이지가 아예 없어지는 건 아니고, 주소(`/tags`)는 여전히 접근 가능하다.

```ts
const headerNavLinks = [
  { href: '/', title: 'Home' },
  { href: '/blog', title: 'Blog' },
  { href: '/projects', title: 'Projects' },
  { href: '/study', title: 'Study' },
  { href: '/about', title: 'About' },
]
```

### 2. Projects 데이터 수정

`data/projectsData.ts`의 샘플 데이터를 실제 진행 중인 프로젝트로 교체했다.

```ts
const projectsData = [
  {
    title: '채용공고 트렌드 분석',
    description: '...',
    href: '/tags/job-crawler',  // 태그 페이지로 연결
  },
]
```

### 3. Study 페이지 신규 생성

`data/studyData.ts`와 `app/study/page.tsx`를 새로 만들었다.
Projects 페이지와 동일한 구조로, Card 컴포넌트를 재사용했다.

공부 카테고리: **Backend / ADP / Web Dev**

### 4. Card 컴포넌트 높이 수정

Projects와 Study 페이지에서 카드 내용 길이가 달라 높이가 맞지 않는 문제가 있었다.

원인은 두 가지였다.
- 이미지가 없을 때 `h-full`이 적용되지 않아 카드 내부가 높이를 채우지 못함
- 카드 내부가 flex column 구조가 아니어서 "Learn more" 버튼 위치가 내용 길이에 따라 달라짐

수정 내용:

```tsx
// Before
<div className={`${imgSrc && 'h-full'} overflow-hidden ...`}>
  <div className="p-6">

// After
<div className="h-full overflow-hidden ...">
  <div className="flex h-full flex-col p-6">
    <p className="... grow">  {/* 설명 텍스트가 남은 공간을 채움 */}
```

`grow`를 설명 텍스트에 주면 버튼은 항상 카드 하단에 고정된다.

## 메인 페이지 개편

기본 템플릿의 메인 페이지는 "Latest" 헤딩과 최근 글 목록만 있었다.
처음 방문한 사람이 이 블로그가 어떤 블로그인지 바로 알 수 없는 구조였다.

세 가지를 추가했다.

1. **프로필 섹션**: 아바타, 이름, 블로그 설명, GitHub/About 링크
2. **Projects 섹션**: 진행 중인 프로젝트 목록 (전체 보기 링크 포함)
3. **Study 섹션**: 공부 카테고리 목록 (전체 보기 링크 포함)

`app/Main.tsx`에서 `projectsData`와 `studyData`를 직접 import해서 렌더링했다.
